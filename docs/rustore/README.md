# Пакет для публикации Shalter в RuStore

## Файл версии

- APK: `public/downloads/Shalter.apk`
- Версия: `1.0.1`
- `versionCode`: `10001`
- Package name: `ru.shalter.app`
- Минимальная версия Android: 8.0 (API 23)
- Target SDK: 35
- Тип: бесплатное приложение с необязательными платными функциями

## Название

**Shalter — мессенджер**

## Краткое описание

Чаты, группы, каналы, истории, боты и голосовые и видеозвонки в одном приложении.

## Полное описание

Shalter — современный мессенджер для личного общения, групп и каналов.

Возможности приложения:

- личные чаты, группы и каналы;
- голосовые и видеозвонки;
- отправка фотографий, видео, файлов, голосовых сообщений и геопозиции;
- истории, реакции, стикеры и подарки;
- боты и мини-приложения;
- вход по паролю, QR-коду и ключу доступа;
- подключение нескольких устройств и управление активными сеансами;
- настройки приватности, блокировка пользователей и жалобы на контент;
- экспорт данных и удаление аккаунта в настройках.

Приложение работает на Android 8.0 и новее. Основные функции доступны бесплатно. Отдельные функции и цифровые товары могут быть платными — условия и цена показываются до подтверждения покупки.

## Возрастной рейтинг

Рекомендуем выбрать рейтинг по фактическому пользовательскому контенту и ответам анкеты RuStore. В описании указать, что пользователи могут отправлять собственный текст и медиа, а в приложении есть жалобы и блокировка.

## Декларация разрешений

| Разрешение | Зачем нужно |
|---|---|
| Камера | Видеозвонки, фото и видеосообщения, сканирование QR-кода входа. |
| Микрофон | Голосовые сообщения и голосовые/видеозвонки. |
| Контакты | Поиск знакомых, которые разрешили использовать контакты для поиска. Функция необязательна. |
| Геопозиция | Отправка геопозиции и функция «Люди рядом». Функция необязательна. |
| Фото и видео | Выбор медиа для отправки в чаты и сохранение полученных файлов. Функция необязательна. |
| Уведомления | Новые сообщения и входящие звонки. Пользователь может отказать в разрешении. |
| Полноэкранные уведомления | Показ экрана входящего звонка, когда приложение не открыто. |

## Комментарий модератору

> Shalter — мессенджер с чатами, группами, каналами и звонками. Для проверки доступны регистрация и вход по email, гостевой режим и QR-вход. Тестовый аккаунт предоставлен в поле комментария к заявке. Камера и микрофон используются только для звонков, голосовых сообщений и QR-сканера. Контакты, геопозиция и медиатека являются необязательными функциями. В приложении доступны жалобы на контент, блокировка пользователей, политика конфиденциальности и удаление аккаунта.

## Важная проверка перед отправкой

В проекте есть функция пользовательского прокси. Правила RuStore отдельно запрещают приложения, которые могут работать как произвольный proxy/VPN/туннель для обхода ограничений. Для RuStore-сборки раздел прокси нужно удалить или ограничить инфраструктурой одной организации до загрузки APK.
