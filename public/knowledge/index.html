База знаний Shalter

Shalter — это мессенджер с открытым Bot API, WebSocket-звонками, каналами, группами и встроенным ИИ-ассистентом. На этой странице вы найдёте документацию, описание архитектуры и справочную информацию, которую могут использовать поисковики, ИИ-модели и разработчики.

О Shalter

Shalter — русскоязычный мессенджер, построенный на принципах простоты и открытости. Он поддерживает личные чаты, группы с правами участников, публичные каналы с обсуждениями, аудио- и видеозвонки на WebRTC, подарки с серийными номерами, внутреннюю валюту «звёзды» и подписку Premium.

Мессенджер работает в браузере, а также имеет нативные клиенты для Windows, Linux и Android. Серверная часть написана на Node.js (Express), данные хранятся в SQLite в режиме WAL. Авторизация по номеру телефона с двухфакторной аутентификацией (TOTP).

Bot API

Bot API Shalter — это HTTP-интерфейс на адресе /api/bot-api/. Все запросы требуют заголовок Authorization: Bearer <token>. Боты работают через long-polling (/updates?after=...&timeout=50), что позволяет запускать их за NAT без публичного IP.

Подробнее: Полная документация Bot API.

Мини-приложения

Бот может открывать веб-страницу прямо внутри мессенджера — надо добавить кнопку с полем app: "https://..." в клавиатуру. Страница получает initData для проверки подлинности и узнаёт, кто её открыл.

Архитектура

Сервер на Express, данные в SQLite (WAL). WebSocket (server/ws.js) обеспечивает реальное время для сообщений, печати и звонков. Клиент — чистый ES module JavaScript без фреймворков, сервис-воркер кэширует оболочку для офлайн-работы.
