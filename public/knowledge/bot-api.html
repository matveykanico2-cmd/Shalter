Bot API — справочник

Все методы доступны по адресу /api/bot-api/ с заголовком Authorization: Bearer <token>. Ответы в JSON.

Авторизация

Authorization: Bearer <token>

Без заголовка — 401 Missing Authorization. С неверным токеном — 401 Invalid bot token. Боты не используют куки: аутентификация только по токену.

Получение обновлений (long-polling)

GET /api/bot-api/updates
ПараметрТипОписание
afterстрока, ISO 8601Время последнего разобранного сообщения.
timeoutчисло, секунды (0–50)Длинный опрос: сервер держит запрос до первого сообщения.
limitчисло (1–200)Максимум сообщений за один запрос.

Следующее значение after — это messages.at(-1).createdAt. Без timeout запрос возвращает пустоту сразу — используйте long-polling для мгновенных ответов.

sendMessage

POST /api/bot-api/sendMessage
ПолеТипОписание
chatIdстрока, обязательноКуда писать — из msg.chatId входящего.
textстрока, обязательноТекст сообщения (до 4096 символов).

sendMessageToUser

POST /api/bot-api/sendMessageToUser

Написать первым пользователю. Требует username или userId, text и опциональную keyboard. Ограничение: 20 новых диалогов в час (429).

sendPhoto

POST /api/bot-api/sendPhoto

Файл передаётся ссылкой (url, http(s)://) или data:-строкой; другой адрес — 400. Поля: chatId, url, caption, replyToId.

sendDocument

POST /api/bot-api/sendDocument

Файл по ссылке (url). Поля: chatId, url, name, caption, replyToId.

sendVideo

POST /api/bot-api/sendVideo

Аналогично sendPhoto для видео. Поля: chatId, url, caption, replyToId, name.

sendVoice

POST /api/bot-api/sendVoice

Голосовое сообщение по ссылке (url). Дополнительно durationSec. Поля: chatId, url, caption, replyToId, durationSec.

sendVideoNote

POST /api/bot-api/sendVideoNote

Круглое видеосообщение. Поля: chatId, url, caption, replyToId, durationSec.

sendSticker

POST /api/bot-api/sendSticker

Стикер по эмодзи. Поля: chatId (обязательно), emoji (обязательно), name, scene, replyToId.

sendPoll

POST /api/bot-api/sendPoll

Опрос с 2–8 вариантами. Поля: chatId, question, options (массив строк), replyToId.

sendLocation

POST /api/bot-api/sendLocation

Точка на карте. Поля: chatId, lat, lng, caption, replyToId.

sendContact

POST /api/bot-api/sendContact

Контакт. Поля: chatId, name, phone, userId, replyToId.

sendMediaGroup

POST /api/bot-api/sendMediaGroup

Альбом до 10 файлов одним сообщением. items — массив { kind, url, name }. Виды: image, video, file, voice, video-note.

editMessageText

POST /api/bot-api/editMessageText

Редактировать своё сообщение. Поля: messageId, text. Чужие сообщения не редактируются (403).

deleteMessage

POST /api/bot-api/deleteMessage

Удалить своё сообщение по messageId. Только свои (403).

sendReaction

POST /api/bot-api/sendReaction

Поставить/снять реакцию. Поля: messageId, emoji. Повторный вызов с тем же эмодзи снимает реакцию.

editMessageKeyboard

POST /api/bot-api/editMessageKeyboard

Заменить клавиатуру под своим сообщением. Поля: messageId, keyboard.

forwardMessage

POST /api/bot-api/forwardMessage

Переслать сообщение. Поля: messageId, toChatId. Оба чата должны быть чатами бота.

copyMessage

POST /api/bot-api/copyMessage

Отправить содержимое сообщения без отметки «переслано». Поля: chatId, messageId.

sendChatAction

POST /api/bot-api/sendChatAction

Показать статус «печатает» или загрузки. Поля: chatId, необязательный action (typing, upload_photo, record_video, upload_video, record_voice, upload_voice, upload_document, record_video_note, upload_video_note). Живёт 5 секунд.

Карточка игры в чате. Поля: chatId, gameId.

// Минимальный бот на чистом Node.js (нет зависимостей)
const TOKEN = process.env.SHALTER_TOKEN;
const API = "https://shalter.ru/api/bot-api";
const auth = { Authorization: `Bearer ${TOKEN}`, "Content-Type": "application/json" };

let after = new Date().toISOString();

async function send(chatId, text) {
  await fetch(`${API}/sendMessage`, {
    method: "POST", headers: auth,
    body: JSON.stringify({ chatId, text }),
  });
}

async function tick() {
  const res = await fetch(`${API}/updates?after=${after}&timeout=30`, { headers: auth });
  const { messages } = await res.json();
  for (const msg of messages) {
    after = msg.createdAt;
    if (msg.text === "/start") await send(msg.chatId, "Привет! Я бот.");
    else await send(msg.chatId, `Вы написали: ${msg.text}`);
  }
}

setInterval(() => tick().catch(console.error), 2000);
Ограничения для новых диалогов. sendMessageToUser: максимум 20 новых разговоров в час (429). Человек может запретить ботам писать первыми в настройках конфиденциальности. По номеру телефона искать нельзя.
Бот может только свои сообщения. editMessageText, deleteMessage, editMessageKeyboard — только над сообщениями, отправленными этим ботом. Чужие вернут 403. Отправка заблокировавшему бота или в канал, где бот не админ, — тоже 403. Действия администратора (pin, ban, restrict) требуют назначения бота админом владельцем чата.
