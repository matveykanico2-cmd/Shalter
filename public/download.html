Установить приложение

Как установить на Windows

Распакуйте архив и запустите install.ps1 — правой кнопкой → «Выполнить с помощью PowerShell». Пакет подписан тестовым сертификатом, скрипт сам добавит его в доверенные, отдельных действий не нужно. Если Windows покажет «SmartScreen», нажмите «Подробнее» → «Выполнить в любом случае».

Как установить на Linux

AppImage — не требует установки: сделайте файл исполняемым (chmod +x Shalter.AppImage) и запустите. .deb — для Debian, Ubuntu и производных: sudo apt install ./Shalter.deb.

Как установить на Android

Откройте скачанный .apk. Android спросит разрешение на установку приложений из этого источника — разрешите его в появившемся окне. Приложения нет в Google Play, поэтому обновления ставятся так же, вручную.
